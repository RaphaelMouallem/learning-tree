# Capstone: version a small project

Pick one:
- **Build:** put a small personal project (a script, a website, a notes folder) under Git with at least 8 meaningful commits, two branches and one resolved merge.
- **Write:** write a one-page "Git mental model" explainer in your own words with your own diagram.

## Acceptance criteria
- [ ] History reads clearly: every commit message says what and why
- [ ] At least one branch was merged back
- [ ] Someone else (or you, a week later) can follow the project history
